# Changelog

All notable changes to Peelr will be documented in this file.

## [1.0.0] - 2026-02-22

### 🎉 Initial Release

#### Features
- 5 conversation decks (Friends, Family, Coworkers, Lovers, Strangers)
- 5 depth layers (Surface to Soul Level)
- 500 professionally written questions (20 per deck/layer)
- Swipe gesture support for cards
- Arrow navigation for non-touch devices
- Card sharing with image generation
- Completion card after finishing all questions
- Dark/light mode toggle
- Full English/Spanish bilingual support
- Mobile-first responsive design
- Deck/layer switcher during gameplay
- Sponsored card support
- Playing card aesthetic design

#### Technical
- Pure vanilla JavaScript (no frameworks)
- No build process required
- LocalStorage for preferences
- Canvas API for image generation
- Touch event handling
- Comprehensive i18n system

#### Pages
- Home screen with centered play button
- Category selection with deck descriptions
- Layer selection with depth indicators
- Game screen with swipeable cards
- Completion screen with stats
- "The Peel" story page (fully bilingual)
- "How to Play" instructions (fully bilingual)
- Settings page (dark mode + language)

#### Design
- Josefin Sans typography
- Gold (#D4AF77) accent color
- Playing card aspect ratio (5:7)
- Smooth animations and transitions
- Professional color-coded decks
- Mobile-optimized touch targets
